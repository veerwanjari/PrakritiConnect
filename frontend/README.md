# PrakritiConnect — Frontend

Vite + React 19 + Tailwind CSS client for PrakritiConnect.

See the [root README](../README.md) for full setup and Vercel deployment
instructions. Quick start:

```bash
npm install
npm run dev
```

Vite proxies `/api` to `http://localhost:5050` in development. In production,
set `VITE_API_URL` to your deployed backend URL (see `.env.example`).
